# Pulseboard React SaaS Landing (proof)
AI SaaS marketing site in React + Vite + Tailwind v4. Built to prove the exact shape clients hire for: nav, hero, logo wall, features, how-it-works, pricing, testimonials, FAQ, contact CTA, footer.

**Stack:** React 18 + Vite + Tailwind v4 + lucide-react. One accent (#1677ff), DM Sans, single radius scale.

## Run
```bash
npm i
npm run dev
npm run build
```

## What it proves
- Component map mirrors the brief line by line (App wires 8 section components)
- Mobile menu, FAQ accordion, form success state, scroll reveal with reduced-motion fallback
- SEO basics: title, meta description, OG tags, semantic landmarks, one h1
- Token discipline: accent, ink, and type scale from one theme block, reused everywhere
